# 1. Premiers pas

## Se connecter

1. Rendez-vous sur **`https://votre-domaine/admin/login`**.
2. Saisissez votre **email** et votre **mot de passe**.
3. Vous arrivez sur le tableau de bord.

Si vous oubliez votre mot de passe, contactez un autre administrateur — il pourra le réinitialiser depuis la section *Utilisateurs*.

## Naviguer dans l'administration

Une fois connecté, le menu latéral donne accès à toutes les sections :

- **Tableau de bord** — vue d'ensemble.
- **Actualités** — articles, brèves, communiqués.
- **Études de cas** — dossiers approfondis sur un sujet ou une zone minière.
- **Ressources** — documents téléchargeables (rapports, lois, fiches).
- **Médias** — bibliothèque d'images.
- **Signalements** — messages reçus depuis le formulaire public.
- **Pages éditoriales** — *À propos*, *Histoire*, *Configuration du site*.
- **Classement** — catégories, mots-clés, régions.
- **Utilisateurs** — comptes administrateurs.
- **Statistiques** — consultations du site.

## Mode clair / mode sombre

Le bouton soleil/lune en haut à droite bascule l'interface en mode sombre. Votre choix est mémorisé.

## Se déconnecter

Cliquez sur votre nom (en haut à droite) puis sur **Se déconnecter**. Pensez à le faire si vous travaillez sur un poste partagé.

# 2. Tableau de bord

C'est la première page après connexion. Elle donne une vue d'ensemble en un coup d'œil.

## Ce que vous y voyez

- **Compteurs** : nombre total d'études de cas, d'actualités, de signalements reçus, et de vues cumulées sur le site.
- **Derniers signalements** : les messages récents envoyés depuis le formulaire public — pratique pour réagir vite.
- **Dernières études de cas** : les dossiers récemment ajoutés ou modifiés, avec leur statut (publié ou brouillon).

## Comment l'utiliser

Le tableau de bord n'est pas une zone d'édition : c'est un **panneau de contrôle**. Cliquez sur un élément pour aller directement à sa fiche détaillée.

> Conseil : commencez chaque session par un coup d'œil aux signalements en attente — vous éviterez d'oublier une demande.

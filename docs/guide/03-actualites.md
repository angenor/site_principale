# 3. Gérer les actualités

Les actualités regroupent les **articles**, **brèves** et **communiqués** publiés sur le site.

## Voir la liste

Section **Actualités** du menu. Vous y trouvez :

- une **barre de recherche** par titre,
- un **filtre** par statut (publié, brouillon, tous),
- la **pagination** en bas.

Chaque ligne affiche le titre, l'image de couverture, la date, l'auteur, le nombre de vues et le statut.

## Créer une actualité

1. Cliquez sur **« Nouvelle actualité »**.
2. Remplissez le formulaire :
   - **Titre** : court et explicite.
   - **Résumé** : 1 à 3 phrases qui apparaîtront sur les listes et aperçus.
   - **Image de couverture** : choisie depuis la médiathèque.
   - **Contenu** : le texte complet de l'article (avec mise en forme).
   - **Auteur** *(optionnel)* — peut être laissé vide.
   - **Lien externe** *(optionnel)* — si l'article renvoie vers un autre site, collez l'adresse ici.
   - **Étiquette** : *Standard*, *Tendance* ou *À la une*. Permet de mettre en avant l'article (avec une date d'expiration optionnelle).
3. Cliquez sur **Enregistrer**.

L'article est créé en **brouillon** par défaut.

## Publier ou dépublier

Sur la fiche de l'actualité (ou directement depuis la liste), basculez le statut **Publié**. Vous pouvez le retirer à tout moment.

## Modifier ou supprimer

- **Modifier** : icône crayon sur la ligne.
- **Supprimer** : icône poubelle. Une confirmation est demandée — la suppression est définitive.

## Bonnes pratiques

- Une **bonne image de couverture** double l'engagement.
- Le résumé doit pouvoir être lu seul : les visiteurs s'en servent pour décider de cliquer.
- Utilisez l'étiquette *À la une* avec parcimonie pour conserver son impact.

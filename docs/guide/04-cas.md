# 4. Gérer les études de cas

Une étude de cas est un **dossier approfondi** sur une situation minière : enquête, suivi d'impact, analyse d'un site précis.

## Créer une étude de cas

1. Section **Études de cas** → **« Nouvelle étude »**.
2. Renseignez :
   - **Titre** du dossier.
   - **Résumé** affiché sur la liste publique.
   - **Image de couverture**.
   - **Contenu détaillé** : texte structuré, sous-titres, citations, témoignages.
   - **Région** concernée (sélection dans la liste — voir [Classement](./10-classement.md)).
   - **Catégories** et **mots-clés** pour faciliter la recherche.
   - **Documents associés** *(optionnel)* : rapports, preuves, annexes — sélectionnés depuis les ressources existantes.
3. **Enregistrer**, puis **Publier** quand le dossier est prêt.

## Différence avec une actualité

| Actualité | Étude de cas |
|-----------|--------------|
| Court, événementiel | Long, analytique |
| Information ponctuelle | Dossier construit dans le temps |
| Affichée sur la page d'accueil | Mise en avant dans la rubrique dédiée |

## Mettre à jour un dossier vivant

Une étude de cas peut évoluer (nouveaux développements, suivi). Modifiez-la directement — la date de dernière modification est mise à jour automatiquement.

## Supprimer

Une étude supprimée est retirée définitivement. Si vous voulez la retirer temporairement, **dépubliez-la** plutôt.

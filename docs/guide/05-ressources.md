# 5. Gérer les ressources documentaires

Les ressources sont les **documents téléchargeables** mis à disposition du public : rapports, lois, fiches, études, présentations.

## Ajouter une ressource

1. Section **Ressources** → **« Nouvelle ressource »**.
2. Remplissez :
   - **Titre** du document.
   - **Description** courte.
   - **Catégorie de ressource** (Rapports, Législation, Outils… — gérée séparément).
   - **Fichier** : téléversez le PDF, DOCX, XLSX… directement depuis votre ordinateur.
   - **Image d'aperçu** *(optionnel)* : couverture du document.
   - **Auteur / Source** *(optionnel)*.
   - **Date de publication**.
3. **Enregistrer**.

## Catégories de ressources

Gérées dans la section **Catégories de ressources** du menu. Créez-en autant que nécessaire (Rapports annuels, Textes de loi, Boîte à outils…). Une ressource appartient à **une seule catégorie**.

## Modifier ou remplacer un fichier

Ouvrez la ressource → modifiez les champs ou téléversez un nouveau fichier. L'ancien est remplacé.

## Visibilité

Comme pour les autres contenus, une ressource peut être **publiée** ou en **brouillon**. Dépubliez-la pour la retirer du site sans la supprimer.

## Conseil

Donnez des **titres clairs** et **datés** (ex. *Rapport annuel 2024 — TI Madagascar*) — c'est ce que les visiteurs verront.

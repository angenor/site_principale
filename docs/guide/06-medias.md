# 6. Gérer la médiathèque

La médiathèque est la **bibliothèque centrale d'images** de la plateforme. Toute image utilisée dans une actualité, une étude de cas ou une page passe par ici.

## Téléverser une image

1. Section **Médias** → **« Téléverser »**.
2. Sélectionnez un ou plusieurs fichiers depuis votre ordinateur.
3. Renseignez (recommandé) :
   - **Titre** de l'image.
   - **Texte alternatif** : description courte pour l'accessibilité et le référencement.
4. L'image est immédiatement disponible dans tous les formulaires.

## Réutiliser une image

Lors de la création d'une actualité ou d'une étude de cas, le sélecteur d'image ouvre la médiathèque. Cliquez sur l'image voulue — pas besoin de la téléverser à nouveau.

## Supprimer

Attention : si une image est **utilisée par un contenu publié**, la supprimer cassera l'affichage. Vérifiez d'abord, ou remplacez l'image dans les contenus avant suppression.

## Bonnes pratiques

- **Format** : JPG ou WEBP pour les photos, PNG pour les logos et illustrations.
- **Poids** : compressez les images lourdes avant téléversement (idéalement < 500 Ko).
- **Dimensions** : 1600 px de large suffit pour une couverture pleine largeur.
- **Texte alternatif** : décrivez ce qu'on voit, pas le mot « image » (ex. *Mine d'or à Andilamena, 2024*).

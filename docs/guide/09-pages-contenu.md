# 9. Pages éditoriales et configuration

Ces sections concernent le **contenu fixe** du site : pages institutionnelles, paramètres généraux.

## À propos

Section **À propos** du menu admin. Elle alimente la page publique `/a-propos`.

Champs modifiables :

- **Mission** de l'observatoire.
- **Présentation** des organisations (TI Madagascar, PCQVP).
- **Équipe** *(le cas échéant)*.
- **Partenaires** et logos.

Modifiez le texte, enregistrez : la page publique est mise à jour immédiatement.

## Histoire (Timeline)

Section **Histoire** (Timeline) : la frise chronologique des événements marquants.

Pour ajouter un événement :

1. **« Nouvel événement »**.
2. Renseignez :
   - **Année**.
   - **Titre** court.
   - **Description**.
3. **Enregistrer**.

Les événements sont automatiquement triés par année sur la page publique.

## Contenu général

Section **Contenu** : textes courts et éléments réutilisables (slogans, blocs d'introduction de la page d'accueil, mentions légales, etc.). Modifiez les blocs présentés.

## Configuration du site

Section **Configuration** : paramètres généraux.

- **Nom du site** et **slogan**.
- **Logo** (clair et sombre).
- **Coordonnées** (adresse, téléphone, email de contact).
- **Réseaux sociaux** (liens Facebook, X/Twitter, LinkedIn, YouTube).
- **Texte du pied de page**.
- **Paramètres SEO** : description par défaut, image de partage.

Toute modification est immédiate sur le site public.

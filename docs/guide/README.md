# Guide de la plateforme MOM

Bienvenue sur le guide d'utilisation de l'**Observatoire des Mines de Madagascar**. Ce guide vous explique, sans jargon technique, comment gérer le contenu de votre plateforme.

## À qui s'adresse ce guide ?

Aux **administrateurs** et **éditeurs** de la plateforme : équipes TI Madagascar et PCQVP responsables de la publication des contenus.

## Logique générale

L'administration se trouve à l'adresse **`/admin`**. Toute personne ayant un compte autorisé peut y accéder. Chaque section suit le même schéma :

- une **liste** des éléments existants (avec recherche et filtres) ;
- un bouton **« Nouveau »** pour ajouter ;
- des actions **Modifier** / **Supprimer** sur chaque ligne ;
- un bouton **Publier / Dépublier** pour rendre visible (ou non) sur le site public.

> Astuce : un contenu non publié reste invisible pour les visiteurs. Vous pouvez préparer vos articles tranquillement et les publier plus tard.
